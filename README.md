## ⚡ 2. Launch Interactive Control Center (on Your Machine)

To connect the ecosystem to your local **Claude Code** environment (`~/.claude/`), run **1 single command in your terminal**:

### 💻 Windows (PowerShell):
```powershell
irm https://raw.githubusercontent.com/temkalt/claude-ultimate-hub/main/install.ps1 | iex
```

### 🐧 Linux & macOS (Bash):
```bash
curl -fsSL https://raw.githubusercontent.com/temkalt/claude-ultimate-hub/main/install.sh | bash
```

### 🎯 What Happens Automatically:
1. Terminal checks your environment (Node.js, Git, Claude CLI).
2. The local execution bridge starts at `http://localhost:3456/`.
3. **Your browser automatically opens** with the full interactive Control Center:
   - **🌟 14 Ready Profiles**: 1-click apply to your local `~/.claude/settings.json`.
   - **🧩 Visual Assembler**: Custom builds with live context token estimation.
   - **📁 Multi-Workspace Scanner**: Auto-detects project frameworks and generates local `.claude/`.
   - **🌐 MCP Manager with Live Ping**: Live connection tester and database connector.
   - **🎯 SKILL.md Creator**: Visual instructions authoring studio.
   - **🤖 Subagents Studio (80+ Roles)**: Opus, Sonnet, and Haiku personas.
   - **📝 CLAUDE.md Auto-Optimizer**: NLP instruction compression (-53% tokens).
   - **🩺 System Doctor**: 15-factor live diagnostic checks with 1-click auto-repair.
   - **⏪ Time-Machine Snapshots**: Automated backups and 1-click configuration rollback.
   - **⚡ Live Streaming Terminal**: Real-time execution logs and output.
