## ⚡ Запуск Веб-Центра Управления (через 1 команду)

Запустите визуальный центр управления прямо в браузере одной командой:

```bash
npm start
```
*Или дважды кликните по `start.bat` в Windows.*

Локальный сервер стартует на `http://localhost:3456/` и автоматически открывает студию:
- **🌟 Готовые Профили**: Применение в 1 клик любого из 12 инженерных профилей.
- **🧩 Конструктор Сборки**: Выбор любых компонентов из 1,000+ каталога с пересчетом токенов в реальном времени.
- **🌐 Менеджер MCP Серверов**: Тестирование связи и управление API-ключами в интерфейсе.
- **🎯 Магазин Скиллов и Плагинов**: 320+ скиллов и 120+ плагинов с 1-клик установкой.
- **🤖 Студия Субагентов**: 50+ ролей инженеров и маркетологов на Opus/Sonnet/Haiku.
- **📝 Строитель CLAUDE.md**: Визуальный редактор с защитой от раздувания токенов (<200 строк).
- **🛡️ 7 Слоев Защиты**: Визуальный редактор разрешений и хуков PreToolUse.
- **🩺 Доктор Системы**: 15-факторная диагностика с авторемонтом в 1 клик.
- **⏪ Снапшоты и Откаты**: Автоматические бэкапы конфигураций и мгновенное восстановление.
- **⚡ Live-Терминал**: Потоковый вывод логов исполнения в реальном времени через SSE.
