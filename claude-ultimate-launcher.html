🛠️ Интерактивный Конструктор Скиллов (`SKILL.md`)

Создайте свой собственный навык по официальному стандарту Anthropic. Сгенерированный файл `SKILL.md` содержит валидную YAML-шапку и активируется Claude Code автоматически при необходимости.

ПРЕДПРОСМОТР SKILL.MD ~/.claude/skills/<name>/SKILL.md
